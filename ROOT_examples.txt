============================================================
ROOT QUICK REFERENCE — Collider to Cosmos
============================================================

Personal cheat sheet for inspecting the current particle-level
ROOT output produced by analysis/particle_level.cpp.


============================================================
BASIC ROOT COMMANDS
============================================================

1. OPEN THE ROOT FILE
------------------------------------------------------------

From the analysis directory:

root -l particle_level.root

-l = start ROOT without the startup splash.


2. EXIT ROOT
------------------------------------------------------------

.q


3. LIST STORED OBJECTS
------------------------------------------------------------

.ls

Useful for checking the available histogram names.

JET RECONSTRUCTION
------------------------------------------------------------

Algorithm:
    anti-kT

Radius:
    R = 0.4

Jet input:
    Stable final-state visible particles.

Excluded from jet clustering:
    neutrinos and muons

Minimum reconstructed jet pT:
    pT > 25 GeV

Jet acceptance:
    |eta| < 4.5

Tagging jets:
    Two highest-pT selected jets.


VBS JET SELECTION
------------------------------------------------------------

Leading jet:
    pT > 65 GeV

Subleading jet:
    pT > 35 GeV

Dijet invariant mass:
    m_jj > 500 GeV

Rapidity separation:
    |Delta y_jj| > 2


DRESSED LEPTONS
------------------------------------------------------------

Prompt electron/muon candidates are identified from the
generated W-boson decay history.

Stable photons within

    Delta R(l, gamma) < 0.1

are added to the lepton four-momentum.

Current dressed-lepton acceptance:

    pT > 27 GeV
    |eta| < 2.5

Event requirements:

    exactly two selected dressed leptons
    same-sign leptons
    m_ll > 20 GeV


MISSING TRANSVERSE MOMENTUM
------------------------------------------------------------

Particle-level MET is constructed from stable neutrinos.

Requirement:

    MET > 30 GeV

============================================================
IMPORTANT STATUS / CAVEATS
============================================================

This is the current SM particle-level baseline analysis.

It is ATLAS-inspired, but it is NOT yet an exact reproduction
of the final ATLAS particle-level fiducial definition.

Remaining refinements include:

    - exact prompt-photon treatment
    - electron-jet overlap removal
    - b-jet veto
    - full normalization / event-weight treatment
    - comparison with unfolded ATLAS / HEPData results
    - validation of the complete fiducial definition

The current histograms are not all filled after the same
selection stage.

For example:

    h_mjj:
        filled for events with >= 2 selected jets

    h_mll:
        filled after the two-lepton + same-sign requirement

Therefore histogram entry counts should always be interpreted
together with the corresponding selection stage.
