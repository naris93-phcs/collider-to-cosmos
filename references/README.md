# Scientific References — Collider to Cosmos

## ATLAS 2019 — Same-Sign WWjj Observation

- Paper: Observation of Electroweak Production of a Same-Sign W Boson Pair in Association with Two Jets in pp Collisions at sqrt(s) = 13 TeV with the ATLAS Detector
- arXiv: https://arxiv.org/abs/1906.03203
- Journal: Physical Review Letters 123, 161801 (2019)
- Local file: papers/ATLAS_2019_SSWWjj.pdf

Role:
- Historical ATLAS observation of electroweak same-sign WWjj production.
- Reference for understanding the earlier event selection and measurement strategy.
- Compare its fiducial definitions with the updated 2024 analysis.

## ATLAS 2024 — Same-Sign WWjj Measurement and Interpretation

- Paper: Measurement and interpretation of same-sign W boson pair production in association with two jets in pp collisions at sqrt(s) = 13 TeV with the ATLAS detector
- arXiv: https://arxiv.org/abs/2312.00420
- DOI: https://doi.org/10.1007/JHEP04(2024)026
- Local file: papers/ATLAS_2024_SSWWjj.pdf

Role:
- Primary reference for the Standard Model EW same-sign WWjj validation.
- Reference for particle-level fiducial definitions and differential observables.
- Reference for EW, QCD and interference modelling.
- Later reference for doubly charged Higgs bosons in the Georgi-Machacek model.

## Research Rules

1. Do not assume that the 2019 and 2024 fiducial definitions are identical.
2. Distinguish reconstruction-level selections from particle-level fiducial definitions.
3. Cite the paper, section, table or figure when extracting analysis requirements.
4. Compare published definitions with the actual C++ implementation before claiming validation.
5. Document any approximations, discrepancies and unresolved questions.
6. Do not change analysis code based on a paper without explicit researcher approval.
