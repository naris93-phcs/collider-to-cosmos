------------------------------------------------------------
  fiducial_events->Print();         Show schema, branches and types
  fiducial_events->GetEntries();    Number of final selected events: 339
  fiducial_events->Show(0);         Show ALL branch values for entry 0
  fiducial_events->Show(10);        Show ALL branch values for entry 10

  Available branches (all Double_t):
    mjj          dy_jj          mll           met
    lepton1_pt   lepton2_pt     jet1_pt       jet2_pt

  Scan a few entries (third argument = options, fourth = max rows):
  fiducial_events->Scan("mjj:dy_jj:mll", "", "", 5);
  fiducial_events->Scan("lepton1_pt:lepton2_pt:met", "", "", 10);
  fiducial_events->Scan("jet1_pt:jet2_pt:mjj", "", "", 10);
  fiducial_events->Scan("mjj:dy_jj:mll:met:lepton1_pt:lepton2_pt:jet1_pt:jet2_pt", "", "", 3);
  fiducial_events->Scan("*", "", "", 5);

  NOTE: Show(0) refers to the FIRST SELECTED event, not event 0
  in the original 10,000-event HepMC sample.


C. QUERY / FILTER THE SELECTED EVENTS
------------------------------------------------------------
  Count events satisfying an additional condition:
  fiducial_events->GetEntries("mjj>1000");
  fiducial_events->GetEntries("dy_jj>3");
  fiducial_events->GetEntries("met>100");
  fiducial_events->GetEntries("mjj>1000 && dy_jj>3");

  Inspect only entries passing an additional condition:
  fiducial_events->Scan("mjj:dy_jj", "mjj>1500", "", 10);
  fiducial_events->Scan("lepton1_pt:met", "met>100", "", 10);
  fiducial_events->Scan("jet1_pt:jet2_pt", "jet1_pt>150", "", 10);

  REMEMBER: These filters act on the ALREADY SELECTED 339 events.
  They do not reprocess the original 10,000 HepMC events.

4. CURRENT EVENT / OBJECT DEFINITIONS (SOURCE CODE)
============================================================

Input:
  ../sm_wpwpjj_leptonic/Events/run_04/tag_1_pythia8_events.hepmc

Jet clustering:
  FastJet anti-kT, R=0.4
  Stable visible particles, excluding neutrinos and muons
  Electrons and photons included in clustering inputs
  Jet acceptance: |eta| < 4.5
  VBS jet candidates: pT >= 25 GeV
  Tagging jets: two highest-pT selected jets

Prompt signal leptons (generator-history approximation):
  Stable e/mu with direct hard-W decay lineage, following
  W-copy and same-lepton-copy chains.

Photon dressing:
  Bare-lepton direction used for DeltaR(l,gamma) < 0.1
  Reject photons with hadron-decay ancestry (approximation)
  Assign each eligible photon uniquely to nearest bare lepton
  Add photon four-momentum to the lepton four-momentum
  Selected dressed leptons: pT > 27 GeV, |eta| < 2.5

Electron-jet overlap removal:
  For electron-jet DeltaR < 0.4 and jet pT >= 25 GeV:
    if pT(e)/pT(jet) < 0.5, remove electron;
    otherwise remove overlapping jet.
  Applied before VBS jet selection.

Lepton / event selection:
  Exactly 2 selected dressed leptons
  Same electric charge (the current signal is W+W+)
  m_ll > 20 GeV
  Third prompt-lepton veto: no >2 prompt e/mu with
    pT > 3 GeV and |eta| < 2.5 (source approximation)
  Dielectron-only Z-window veto: |m_ll - 91.1876| >= 15 GeV
  MET > 30 GeV

MET:
  Magnitude of vector sum of stable-neutrino transverse momenta
  (not a detector-reconstructed missing-energy measurement).

b-jet veto:
  Approximate last-open-bottom-hadron ghost association
  Veto a tagged jet with pT > 20 GeV and |eta| < 2.5
  This is not yet a fully verified official ATLAS weakly-
  decaying-b-hadron truth definition.

VBS topology:
  >=2 jets with pT >= 25 GeV and |eta| < 4.5
  Leading jet pT >= 65 GeV
  Subleading jet pT >= 35 GeV
  m_jj > 500 GeV
  |Delta y_jj| > 2

7. PHYSICS REMINDERS
============================================================

  m_jj^2 = (p_j1 + p_j2)^2
  m_ll^2 = (p_l1 + p_l2)^2
  pT = sqrt(px^2 + py^2)
  y = 0.5 * ln((E+pz)/(E-pz))
  |Delta y_jj| = |y_j1 - y_j2|

For approximately massless jets:
  m_jj^2 ~ 2 pT1 pT2 [cosh(Delta y) - cos(Delta phi)]

Large dijet mass and large rapidity separation are characteristic
of VBS-like tagging-jet topologies, not mandatory for every
generated electroweak event.

Implemented:

  - Direct hard-W lepton-lineage selection (signal approximation)
  - Bare-cone photon dressing with unique photon assignment
  - Electron-jet overlap removal
  - Approximate b-hadron ghost-matched b-jet veto
  - Third-lepton and dielectron Z-window vetoes
  - Unified cumulative cutflow
  - Selected-event ROOT TTree and normalized shape plots
  - Paired old/new dressing and MET-closure diagnostics

  - Proper fiducial cross-section calculation
  - Relevant backgrounds / other charge channels as needed
  - Statistical and systematic uncertainty treatment
  - Comparison with published ATLAS/HEPData distributions
  - BSM Georgi-Machacek implementation and parameter scan

The current output is a functioning SM particle-level baseline,
NOT a complete experimental validation or BSM result.

9. TROUBLESHOOTING
============================================================

Error: Cannot open particle_level.root
  Check 'pwd' and 'ls particle_level.root'. Run macros from
  analysis/ or pass the correct input file path.

Error: missing fiducial_events tree
  Check '.ls' in ROOT; confirm this is the latest output file.

Why do diagnostic histogram entries differ?
  Histograms are filled at different stages of the event loop.
  The final TTree always stores only full-selection events.

Why do final plots have vertical lines?
  They ARE histograms, drawn with statistical error bars.

Why does ROOT close plots?
  Batch execution exits, and the macro uses local canvases.
  Inspect saved PNGs independently in Windows Explorer.
