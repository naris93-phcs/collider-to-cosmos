# Curated four-sample baseline

Start with the [results index](../docs/RESULTS_INDEX.md). The links below point to the original validated outputs in the manual EW negative-charge analysis directory. They need that directory to resolve in a fresh checkout. The machine-readable [sample manifest](samples.json) uses paths relative to the repository root; null seeds or paths denote unverified provenance or unavailable inputs.

- [Figure PDF](four_sample_fiducial.pdf) and [PNG](four_sample_fiducial.png)
- [Cross sections](cross_sections.csv), [cutflows](cutflow.csv), [binned distributions](distributions.csv) and [comparison JSON](comparison.json)
- [Artifact checksum manifest](SHA256SUMS), checked from the repository root with `sha256sum -c results/SHA256SUMS`

The existing output indices distinguish generator-level and particle-level results. Distributions come from final fiducial trees and include unit-area and cross-section-normalized densities.
