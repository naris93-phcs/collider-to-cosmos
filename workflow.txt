============================================================
3. GIT QUICK REFERENCE
============================================================

Check what changed:
git status

See line-by-line changes:
git diff

Stage a specific file:
git add analysis/particle_level.cpp

Stage everything:
git add .

Commit:
git commit -m "Describe what changed"

Push to GitHub:
git push

Typical workflow:
git status
git diff
git add .
git commit -m "Implement ATLAS-like VBS jet selection"
git push


============================================================
4. COMPILE PARTICLE-LEVEL ANALYSIS
============================================================

# Activate environment
conda activate hep

# Go to project root
cd ~/projects/collider_to_cosmos

# Configure CMake (first time / configuration changes)
cmake -S . -B build -DCMAKE_PREFIX_PATH="$CONDA_PREFIX"

# Compile (after modifying the .cpp)
cmake --build build
  
============================================================
5. RUN PARTICLE-LEVEL ANALYSIS
============================================================

# Go to analysis directory
cd ~/projects/collider_to_cosmos/analysis

# Run the CMake executable
../build/particle_level
  

Typical compile + run workflow:

conda activate hep
cd ~/projects/collider_to_cosmos
cmake --build build
cd analysis
../build/particle_level
