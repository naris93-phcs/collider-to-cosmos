============================================================
4. COMPILE PARTICLE-LEVEL ANALYSIS
============================================================

First go to the analysis directory:

cd ~/projects/collider_to_cosmos/analysis

Activate HEP environment if needed:

conda activate hep

Compile:

g++ -std=c++17 particle_level.cpp \
-I../MG5_aMC_v3_8_0/HEPTools/hepmc/include \
-L../MG5_aMC_v3_8_0/HEPTools/hepmc/lib -lHepMC \
$(fastjet-config --cxxflags --libs) \
$(root-config --cflags --libs) \
-o particle_level


============================================================
5. RUN PARTICLE-LEVEL ANALYSIS
============================================================

HepMC runtime library path:

export LD_LIBRARY_PATH="$HOME/projects/collider_to_cosmos/MG5_aMC_v3_8_0/HEPTools/hepmc/lib:$LD_LIBRARY_PATH"

Run:

./particle_level


Typical compile + run workflow:
